🎬 Projeto de Site | Nayara Soares - Storymaker e Criadora de Conteúdo Digital

Este projeto apresenta o site oficial de Nayara Soares – Storymaker e Criadora de Conteúdo Digital, desenvolvido para destacar sua identidade profissional, serviços e portfólio em um ambiente moderno e responsivo.

O site foi pensado para transmitir credibilidade e criatividade, reunindo informações essenciais, formas de contato e exemplos de trabalhos já realizados, além de facilitar o acesso a orçamentos e interação com clientes.

✨ Funcionalidades

Página inicial (Hero): chamada principal com apresentação e botão para solicitar orçamento via WhatsApp.

Seção Sobre Mim: apresentação da trajetória e motivação profissional.

Portfólio: vídeos de eventos realizados (casamentos, aniversários, chá revelação etc.).

Serviços: descrição das principais soluções oferecidas (filmagem profissional, edição criativa, produção de conteúdo).

Depoimentos: formulário interativo para envio de feedbacks e exibição dinâmica via JavaScript.

Rodapé: redes sociais, informações de contato e formas de pagamento.

Layout responsivo: adaptado para desktop e mobile.

🛠️ Tecnologias Utilizadas

HTML5

CSS3

JavaScript (ES6+)

Font Awesome (ícones)

Google Fonts (Poppins)

📂 Estrutura do Projeto

index.html → Página principal do site.

style.css → Estilos visuais personalizados.

script.js → Funcionalidades dinâmicas (ex.: depoimentos).

assets/ → Imagens, vídeos e outros arquivos estáticos.
